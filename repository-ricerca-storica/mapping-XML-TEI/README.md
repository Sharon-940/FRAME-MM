# Mapping XML-TEI

Questa cartella contiene file di mapping tra le trascrizioni XML-TEI e la rappresentazione della conoscenza all'interno del progetto. Lo scopo di questa sezione è documentare e gestire i collegamenti tra i dati codificati in TEI e la struttura del Knowledge Graph.

## Struttura della cartella
- **Schema di Mappatura**: File che definiscono le corrispondenze tra elementi XML-TEI e le entità/concetti del Knowledge Graph.
- **Script di Trasformazione**: Eventuali script (ad esempio, in Python o XSLT) per automatizzare il processo di conversione e allineamento dei dati TEI con i modelli ontologici.
- **Documentazione**: Note e file di spiegazione sul processo di mappatura e le scelte metodologiche adottate.

## Obiettivi
- Stabilire una connessione semantica tra i testi digitalizzati e le strutture di conoscenza.
- Facilitare l'estrazione di informazioni strutturate dai documenti XML-TEI.
- Integrare i dati testuali con i modelli di knowledge representation esistenti nel progetto.

## Possibili file contenuti
- `mapping-tei-to-rdf.ttl`: Esempio di file Turtle per la conversione dei dati TEI in RDF.
- `mapping-tei-schema.xsl`: Foglio di stile XSLT per trasformare il TEI in un formato compatibile con il Knowledge Graph.
- `mapping-tei-notes.md`: Note metodologiche sulle scelte di mappatura adottate.

Questa cartella è in continuo aggiornamento in base all'evoluzione del progetto e alle necessità di adattamento dei modelli di rappresentazione della conoscenza.
