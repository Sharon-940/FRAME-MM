# XSL

Questa cartella contiene fogli di stile XSL utilizzati per trasformare i file XML-TEI in diversi formati di output. Gli XSLT (Extensible Stylesheet Language Transformations) permettono di manipolare e presentare i dati XML in modo flessibile e strutturato.

## Struttura della cartella
- **tei-to-html.xsl**: Foglio di stile per la conversione dei documenti XML-TEI in pagine HTML leggibili.
- **tei-to-txt.xsl**: Trasformazione dei documenti XML-TEI in formato testuale semplice.
- **tei-to-rdf.xsl**: Conversione dei file XML-TEI in RDF per l'integrazione con il Knowledge Graph.
- **tei-to-pdf.xsl**: Trasformazione XML-TEI in PDF utilizzando XSL-FO.

## Uso dei file XSL
Questi fogli di stile possono essere applicati tramite processori XSLT come Saxon o Xalan per trasformare i file TEI in vari formati, facilitando la loro visualizzazione e l'integrazione con altri sistemi.
