# Scripts-python

Questa cartella contiene script Python utilizzati per l'elaborazione, l'analisi e la trasformazione dei dati all'interno del repository di ricerca storica. Gli script qui archiviati sono finalizzati a supportare l'analisi dei testi, l'estrazione di informazioni, la conversione di formati e altre operazioni legate alla ricerca computazionale.

## Struttura della cartella

- **preprocessing/**: Contiene script per la pulizia e la normalizzazione dei dati prima della loro analisi.
- **tei_processing/**: Racchiude gli script per la manipolazione e la trasformazione di documenti XML-TEI.
- **kg_building/**: Include script per la generazione e l'arricchimento del Knowledge Graph.
- **ontology_mapping/**: Contiene strumenti per il mapping tra dati TEI e ontologie semantiche.
- **utilities/**: Script generici di supporto per operazioni varie, come la conversione di file o l'estrazione di metadati.

## Requisiti

Gli script sono scritti in Python 3 e richiedono alcune librerie di terze parti, installabili tramite:

```
pip install -r requirements.txt
```

## Utilizzo

Ogni script è corredato da una breve documentazione interna che spiega il suo funzionamento e le modalità di esecuzione. Per eseguire uno script:

```
python script_name.py
```

Per dettagli sulle funzioni specifiche, consultare i commenti nei singoli file o la documentazione del repository.

## Manutenzione e contributi

Se si desidera aggiungere nuovi script o modificare quelli esistenti, si prega di documentare adeguatamente le modifiche e seguire le linee guida interne per la scrittura di codice leggibile e manutenibile.
