# knowledge-representation

Questa cartella raccoglie le risorse relative alla rappresentazione della conoscenza nel contesto della ricerca storica dell'architettura. Essa è suddivisa in due sottocartelle principali:

## 1. knowledge-graph
Questa cartella contiene i grafi della conoscenza generati a partire dai dati storici e archivistici. I file presenti in questa cartella possono includere:
- **File RDF/Turtle (.ttl)**: Rappresentazioni strutturate dei dati sotto forma di grafi RDF.
- **File JSON-LD**: Versione serializzata dei grafi della conoscenza in formato JSON.
- **File di query SPARQL**: Query utilizzate per interrogare i grafi della conoscenza.
- **Script Python**: Strumenti per l'elaborazione, la trasformazione e l'analisi dei dati RDF.

## 2. ontologie
Questa cartella contiene le ontologie utilizzate e sviluppate per la modellazione dei dati della ricerca. I file presenti in questa cartella possono includere:
- **ontologie-esistenti**: File OWL, RDF o TTL contenenti ontologie già disponibili e adottate nella ricerca.
- **ontologie-estensioni**: Versioni modificate o estese delle ontologie esistenti.
- **documentazione**: Testi descrittivi che spiegano la struttura e l'uso delle ontologie impiegate.

Questa cartella è fondamentale per la strutturazione e l'organizzazione delle informazioni all'interno del progetto di ricerca.
