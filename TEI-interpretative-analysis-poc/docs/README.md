# Additional Documentation

This directory contains supporting documentation and XML-TEI templates developed for the methodological proof of concept.
Two minimal TEI templates are provided for two types of historical architectural sources:

- **Textual documents:** "tei-minimal-template-textual" provides a basic TEI structure for encoding textual sources, including document metadata and textual content.
- **Graphical documents:** "tei-minimal-template-graphical" provides a basic TEI structure for representing graphical sources through facsimiles, surfaces, and zones.

These templates provide a starting point for the preliminary encoding and structuring of historical sources.
